# [Count 1's in binary array](https://www.geeksforgeeks.org/problems/count-1s-in-binary-array-1587115620/1)
## Easy
You are given a binary array that is sorted in non-increasing order, meaning all the 1's appear before the 0's. Find the total number of 1's present in the array.
Examples:
Input: arr[] = [1, 1, 1, 1, 1, 0, 0, 0]Output: 5Explaination: Count of 1's in the array is 5.
Input: arr[] = [1, 1, 1, 1, 1, 1, 1]Output: 7Explaination: Count of 1's in the array is 7.
Constraints:1 ≤ arr.size() ≤ 105&nbsp;0 ≤ arr[i] ≤ 1
